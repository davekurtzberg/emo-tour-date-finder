# Emo Tour Date Finder — October 2027 Snapshot

A static snapshot of announced tour dates for 32 emo / emo-adjacent bands,
showing which days in October 2027 none of them are playing.

- Data is pulled from public tour listings (each show carries a source link).
- The page is regenerated daily by Atlas from the live tracker; it does not
  fetch anything itself.
- Anything you do on the page — unchecking bands, toggling the travel buffer,
  adding a show by hand — is saved only in your own browser (localStorage).

"Clear" means no announced show in the snapshot data, not confirmed availability.
